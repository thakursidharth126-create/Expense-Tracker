# Expense Tracker

A simple Python-based Expense Tracker that allows user to manage their personal expenses from the terminal.

## Features

- Add expenses
- view all expenses
- Calculate total expenses
- Delete expenses
- Edit expenses
- Search expenses by category or decription
- Sort expenses by amount
- Save expense using JSON
- Load saved expenses when the program starts


## Technologies Used

- Python
- LSON
- Git
- GitHub

## How to Run

1. Clone the repository.
2. open the project folder in VS Code.
3. Open the terminal.
4. Run:

'''bash
python main.py
'''
